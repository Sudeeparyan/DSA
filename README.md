# NeetCode 150 Learn

A mobile-first, offline-friendly study site for the **NeetCode 150** — stories, step-by-step animations, and interview-ready Python.

## Quick start

See **[HOW_TO_RUN.md](./HOW_TO_RUN.md)** for beginner-friendly setup.

```bash
npm install
npm run dev
```

Open http://localhost:3000

## What’s inside

- All **150** problems as validated JSON in `content/problems/`
- Solutions vendored from [`Sudeeparyan/Neetcode150`](https://github.com/Sudeeparyan/Neetcode150) under `solutions/` (Python; C++/Rust not present upstream)
- Reusable visualiser engine + tracers
- Progress, notes, and Leitner revision cards in `localStorage`
- Static export (`output: 'export'`) for GitHub Pages / Vercel
